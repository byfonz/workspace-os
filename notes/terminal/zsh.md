#Overview 
zsh is an interactive shell that super power bash scripts, that handles commands, alias, scripts, prompts. completitions and workflows.

#UseCases


#Installation 
```
sudo pacman -S zsh
```

#Configuration 
###### Set zsh as Default
```
chsh -s /bin/zsh
```

###### Verify
```
echo $SHELL
```

#Concepts
**Aliases**: Shortcuts to commands

#Purpose
tmux or Terminal Multiplexer is a tool that handle multiple terminal sessions allowing multiple terminal programs running in each session. 

#Installation
```
sudo pacman -S tmux
```


#Concepts 
##### Server and Clients



#Configuration
1.- Create Session
```
tmux new -s[session_name]
```

#Commands 
Kill Sessions
```
tmux kill-session -t[session_name]
```
